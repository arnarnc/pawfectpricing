How to Use

A quick guide to getting the most out of this tool.

🔍

Search eBay

Type a card name or product into the search box, then tap one of the three buttons to open eBay results instantly.

1

Global Sold — worldwide sold listings to see what cards have actually sold for.

2

Australia Sold — filters to Australian sold listings only for local pricing.

3

Available — active Buy It Now listings, in eBay's best-match order, to see what the card is going for right now.

Toggle No auctions (top-right of this section) to filter sold results to Buy It Now only — useful for excluding auction outliers.
✨

Autocomplete

Start typing a Pokémon name and a dropdown will suggest matches. Tap a suggestion to fill the search box — it covers all Pokémon and popular trainer names.

🏴

One Piece TCG

Flip the switch above the search box to One Piece and the whole search changes to how that game names cards.

You don't have to remember which tab you're on. Type op01-016 or luffy while the Pokémon tab is showing and it moves itself to One Piece — and back again for charizard 125/197. It only moves when what you typed could only be one game; half a word, a grade or a condition never moves it. When it does move, it says so under the switch, and whatever you'd typed stays put.

Type it the way you'd search it. There's no dropdown to pick from here — whatever you type is very close to what gets searched, so nothing quietly narrows your results behind your back.

Every One Piece card has an ID printed on it — OP01-016 — and no other card in the game shares it, so that ID does most of the work. The character's name goes in too, exactly as you typed it — every word of it, the same way a sealed search sends a set's whole name.

How much of the name you type is how wide the search is. Type luffy and you get every listing with "Luffy" in the title. Type Monkey.D.Luffy and you get the narrower set that spells it out. Sellers mostly title on the short form, so luffy is usually the one you want — but that's your call to make, not the app's, because you're the one holding the card.
Typing is forgiving: op1-16, op01 016, op01016 all reach OP01-016, and p 150 becomes P-150. A grade is safe — psa 10 is never mistaken for a card number.
O and 0 are fixed for you. 0P01-016, OPO1-016 and OP01-O16 all reach OP01-016. There are only five set families — OP, ST, EB, PRB and P — and everything after the family is digits, so there's nothing to guess. Character names are never touched: robin stays robin.

The ID is only half the card. OP01-016 Nami is a $3 Rare, a $400 alternate art, and a $2,000 manga art — same number, three very different cards. So add the printing — and it goes to eBay exactly as you type it. Say alt and it searches "alt", not "alt art"; say treasure and it searches "treasure", not "treasure rare". Type the longer wording yourself if that's what you want.

aa→Alternate art (or type alt, or alt art)
manga→Manga art
sp→SP / special card
fa→Full Art
tr→Treasure rare
pan→Pandaman parallel
tf→Textured Foil
pf→Pirate Foil
serial→Serial-numbered
winner→Winner Version
jr→Judge promo
wanted→Wanted Poster
jp→adds the word "japanese"
en→adds the word "english"
sd→Starter Deck (bbx still means Booster Box)

The badge under the search box always tells you which printing you're pricing — Base Print until you say otherwise.

Cards you've looked up before still appear under the box as you type, so a repeat search is one tap. Nothing else is suggested — the catalogue dropdown is gone on purpose, because picking a row from it was writing a longer, tighter query than the one you meant.

A set code on its own works for sealed: op17 bbx searches that set's booster box by name, since that's how boxes are listed.
↺

Recent Searches

Every card you actually look up — by tapping Global, Australia, Available, or Compare prices — is remembered and pushed to the top of the dropdown next time, most recent first.

So if you check Pikachu 18/091 today and Pikachu 20/200 after it, typing pika tomorrow lists 20/200 first, 18/091 second, then the rest of the catalogue.

The last 2,000 searches are kept. Older ones drop off automatically, so it never slows down.
⇅

Syncing Phone & Desktop

Tap ⇅ at the top of the app to share your recent searches between devices. It stores them in a private gist on your own GitHub account — free, and nothing is made public.

Set it up once per device: create a token from the link in the panel, paste it in, and repeat with the same token on your other device. The second device finds the same gist on its own — there's nothing to copy across.

Without it everything still works — recent searches just stay on the device that made them.
⚡

Shortcuts

Type these short codes anywhere in your search and they expand automatically.

etb→Elite Trainer Box
bbx→Booster Box
nm→Near Mint
lp→Lightly Played
mp→Moderately Played
hp→Heavily Played
dmg→Damaged
Tip: Type Charizard 4 102 nm and it becomes a smart eBay query automatically.
🏆

Graded Cards

Include a grading label and score in your search and the tool automatically switches to Graded Mode, filtering eBay to slabbed cards only.

Examples: PSA 10 · BGS 9.5 · CGC 9 · TAG 10
📋

Comp List

Build a list of cards with prices to calculate a total buy offer for a collection.

1

Type the card name in the search box, enter a $ price, then tap + Add to List.

2

Each row shows the card name and an editable price you can adjust at any time.

3

Tap × to remove a single row, or Clear All to reset the list.

Auto-saved: Your comp list is stored in the browser and survives page refreshes. It only clears when you delete rows.
💸

Payout Percentage

The % column lets you apply a buy percentage to each card. Use the header dropdown to set the same percentage across every row at once.

1

Market Value — total of all raw prices with no discount applied.

2

Payout Offer — total after each card's percentage is applied. This is your buy offer.

Example: $100 @ 80% + $10 @ 70% = $87 payout offer.
